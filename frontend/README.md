# MilletVerse Frontend

This folder contains the React + Vite frontend for the MilletVerse application.

## Local development

```powershell
cd d:\milletverse\frontend
npm install
npm run dev
```

The app starts on `http://localhost:5173` by default.

## Build

```powershell
npm run build
```

## Notes

- The frontend uses `VITE_API_BASE_URL` to point to the backend API in production.
- For local development, the backend should be running on `http://localhost:5000`.
- See the root `README.md` for full project setup and backend configuration.
